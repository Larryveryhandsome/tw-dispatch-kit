# 金鑰申請與設定

開源版**不附任何金鑰**，也不提供我們的帳號。這份文件只教你怎麼用**自己的帳號**申請、填在哪裡。

> 示範版（`demo_server.py`）會強制關閉所有對外連線，就算設了金鑰也不會用。下面的設定只對正式模式（`server.py`）有效。

## 金鑰放哪裡

一律用環境變數，名稱規則是 `DISPATCH_SECRET_` 加上金鑰名稱（大寫）：

| 金鑰名稱（程式裡） | 環境變數 | 用途 |
|---|---|---|
| `line_secret_<品牌id>` | `DISPATCH_SECRET_LINE_SECRET_<品牌ID>` | LINE 官方帳號 Channel secret（驗證 webhook 簽章） |
| `line_token_<品牌id>` | `DISPATCH_SECRET_LINE_TOKEN_<品牌ID>` | LINE 官方帳號 Channel access token（傳訊息） |
| `linepay_channel_id` | `DISPATCH_SECRET_LINEPAY_CHANNEL_ID` | LINE Pay Channel ID（全品牌共用） |
| `linepay_channel_secret` | `DISPATCH_SECRET_LINEPAY_CHANNEL_SECRET` | LINE Pay Channel Secret Key |
| `linepay_channel_id_<品牌id>` | `DISPATCH_SECRET_LINEPAY_CHANNEL_ID_<品牌ID>` | 選用：某個品牌自己的 LINE Pay（沒設就用共用那組） |
| `google_client_id` | `DISPATCH_SECRET_GOOGLE_CLIENT_ID` | Google 日曆同步（OAuth 用戶端） |
| `google_client_secret` | `DISPATCH_SECRET_GOOGLE_CLIENT_SECRET` | 同上 |
| `anthropic_api_key` | `DISPATCH_SECRET_ANTHROPIC_API_KEY` | 記帳：拍收據自動讀金額（選用） |

品牌 id 預設有三個：`demoshop`（示範清潔）、`helper`（居家小幫手）、`bnb`（民宿清潔線），定義在 `app/brands.py`。

設定方式：

```bash
# macOS / Linux
export DISPATCH_SECRET_LINE_SECRET_DEMOSHOP="你的 channel secret"
export DISPATCH_SECRET_LINE_TOKEN_DEMOSHOP="你的 channel access token"
python app/server.py
```

```powershell
# Windows PowerShell（只在這個視窗有效）
$env:DISPATCH_SECRET_LINE_SECRET_DEMOSHOP = "你的 channel secret"
$env:DISPATCH_SECRET_LINE_TOKEN_DEMOSHOP = "你的 channel access token"
python app/server.py
```

- 沒設的金鑰＝那個功能關閉，系統照常運作（例如沒有 LINE Pay 金鑰，客人就只看到匯款資訊）。
- 金鑰**不要**寫進程式、不要 commit 進 git；外流時請立刻到發放處撤銷或重新產生。
- Windows 上也可以在管理畫面輸入金鑰，會用 Windows DPAPI 加密存進資料庫（只有同一個 Windows 帳號解得開）；環境變數優先。

## 1. LINE 官方帳號（Messaging API）

1. 到 [LINE Official Account Manager](https://manager.line.biz/) 建立官方帳號（或用現有的）。
2. 在帳號設定 →「Messaging API」按「啟用 Messaging API」，選擇（或建立）一個 Provider。
3. 到 [LINE Developers Console](https://developers.line.biz/console/)，點進剛剛的 channel：
   - **Basic settings** 分頁：複製 **Channel secret** → `DISPATCH_SECRET_LINE_SECRET_<品牌ID>`
   - **Messaging API** 分頁最下面：按 **Issue** 產生 **Channel access token (long-lived)** → `DISPATCH_SECRET_LINE_TOKEN_<品牌ID>`
4. 同一頁設定 **Webhook URL**：`https://你的網域/line/webhook/<品牌id>`（例如 `https://ops.example.com/line/webhook/demoshop`），打開「Use webhook」。
5. 把你的網域設進 `DISPATCH_PUBLIC_HOSTS`、`DISPATCH_BASE_URL`，並確認外網是 HTTPS（LINE 只接受 HTTPS webhook）。
6. 建議先用一個測試用的官方帳號，加自己為好友試完整流程，再換正式帳號。

## 2. LINE Pay（選用）

1. 到 [LINE Pay 商家中心](https://pay.line.me/tw/center/main) 申請商店（需要公司或行號資料，正式商店審核需要一個已上線、有價格與條款的網站）。
2. 先用 **Sandbox**（測試環境）：在 [LINE Pay Developers](https://pay.line.me/tw/developers/main/main) 申請 sandbox，取得 **Channel ID** 與 **Channel Secret Key**。
3. 設定 `DISPATCH_SECRET_LINEPAY_CHANNEL_ID`、`DISPATCH_SECRET_LINEPAY_CHANNEL_SECRET`。
4. 系統預設是 sandbox 模式（不會真的扣款）；管理畫面「LINE Pay」可以按「測試連線」，會建立一筆 1 元的付款請求確認金鑰與伺服器 IP 都通，不會扣款。
5. 正式商店要在 LINE Pay 商家中心登記伺服器的對外 IP（白名單），測試都通過、真人用自己的帳號付過一筆後，才把模式改成 production。

## 3. Google 日曆同步（選用）

只會讀寫**這個系統自己建立的日曆**（scope：`calendar.app.created`），不會碰你其他的日曆。

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立專案，啟用 **Google Calendar API**。
2. 「API 和服務 → OAuth 同意畫面」：使用者類型選「外部」，測試使用者加入自己的 Google 帳號。
3. 「憑證 → 建立憑證 → OAuth 用戶端 ID」：類型選「網頁應用程式」，授權重新導向 URI 填 `http://127.0.0.1:4781/oauth/callback`（埠改成你的 `DISPATCH_PORT`）。
4. 複製用戶端 ID／密鑰 → `DISPATCH_SECRET_GOOGLE_CLIENT_ID`、`DISPATCH_SECRET_GOOGLE_CLIENT_SECRET`。
5. 在本機打開管理畫面的串接設定，按「連接 Google（在這台電腦按）」完成授權（取得的 refresh token 會存在資料庫）。

## 4. Anthropic API（選用：拍收據自動讀金額）

1. 到 [Anthropic Console](https://console.anthropic.com/) 註冊並儲值，建立 API key（`sk-ant-` 開頭）。
2. 設定 `DISPATCH_SECRET_ANTHROPIC_API_KEY`，並安裝選用套件：`pip install anthropic PyMuPDF`。
3. 建議在 Console 設定每月用量上限。沒設金鑰時，收據照片只存檔，金額由人工填。

## 5. 不需要申請的

- **國土測繪中心定位**：用公開 API，不需要金鑰（要裝 `requests`）。
- **手機推播（Web Push）**：VAPID 金鑰由系統第一次用到時自己產生，存成資料夾裡的 `.pem` 檔（在 `.gitignore` 裡，不會進 git）。
